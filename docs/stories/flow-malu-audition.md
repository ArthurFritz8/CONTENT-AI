## Limite de integração

O Flow utiliza os créditos da assinatura na interface. A API oficial do Veo é uma rota separada, faturada por segundo e sem camada gratuita para geração de vídeo; os 1.050 créditos exibidos no Flow não constituem saldo da API. O Google AI Pro anuncia também US$ 10 mensais em créditos GenAI/Cloud para desenvolvedores, cuja aplicação à API exige verificar elegibilidade, vincular a conta de faturamento e, conforme o plano, possivelmente fazer pré-pagamento. A chave `GEMINI_API_KEY` local respondeu HTTP 200 à consulta somente leitura do modelo `veo-3.1-fast-generate-preview` em 08/10/2026; isso confirma que o modelo é visível para a chave, **não** que a conta tem faturamento habilitado ou créditos aplicados. Nenhuma geração pela API foi enviada nem integração automática com o Flow validada. O renderer do Studio aceita assets `video_clip` ligados a uma cena, mas o painel ainda não tem ingestão de MP4 do Flow nem um worker que os gere via Flow. Importar um MP4 aprovado exigirá implementar essa etapa e continuará sendo manual na origem.

O teste isolado da API está implementado em `scripts/veo-api-audition.py`. `--preflight` valida modelo e referência sem gerar; `--run` envia uma única tomada por referência, registra a operação antes de aguardar, baixa o MP4 e faz auditoria técnica; `--resume` acompanha a mesma operação sem duplicar o envio. A chamada fica travada até existir uma fonte de custeio confirmada e um teto explícito de US$ 0,80. O pré-pagamento mostrado no AI Studio **não foi autorizado nem executado**. Verificar **Google Developer Program → My Benefits** antes de considerar a possível rota Vertex AI com crédito mensal; a existência do benefício e seu uso efetivo nessa conta ainda não foram comprovados. A aprovação visual e editorial continua pendente após a auditoria técnica.

### Rota sem novo desembolso: o que está confirmado

As capturas de 08/10 mostram AI Studio em **pré-pagamento obrigatório**, sem créditos de API, pedindo no mínimo R$ 60. Os 1.050 créditos exibidos antes no Flow são outra carteira: Google AI Pro fornece 1.000 créditos mensais no Flow; na tabela oficial atual, uma geração Veo 3.1 Lite custa 10 e Fast custa 20 créditos, inclusive para tomadas de 8 segundos. É uma estimativa de até 105 Lite ou 52 Fast com 1.050 créditos, antes de retentativas, extensões ou outras gerações. Verificar o custo no próprio Flow antes de cada envio. Nano Banana produz imagens; para vídeo escolher Veo. O Flow Agent pode gerar lotes a partir de instruções e referências usando esses créditos, mas opera **dentro do site**: não foi encontrada API oficial para nosso Studio enviar jobs e debitar a carteira Flow. Não chamar a automação do capítulo inteiro de pronta por causa desse recurso.

Google AI Pro anuncia US$ 10/mês de crédito GenAI/Cloud de desenvolvedor, separado da carteira Flow. O benefício deve aparecer em **Google Developer Program → My Benefits** e ser vinculado à conta de faturamento elegível. O FAQ oficial diz que créditos Cloud podem ser usados em Vertex AI; isso justifica avaliar a API Vertex Veo com um teto de gasto. O projeto AI Studio atual, porém, exige um saldo pré-pago positivo antes de consumir créditos promocionais, por isso **não** se deve executar a API Gemini com sua chave atual. Também não se deve presumir que a API Vertex já esteja ativa, que a concessão mensal tenha aparecido ou que tenha o mesmo bloqueio de cobrança: verificar as três condições na conta real antes de um teste. A conta Google Cloud pode cobrar gastos acima dos créditos se não houver limite efetivo.

**Evidência posterior do operador:** em 08/10 o cartão de US$ 10 mensais aparece na conta Google AI Pro, mas está como `Action Required`, com `Nenhuma conta de faturamento` selecionável. O link `Create Google Cloud Billing Account` leva ao painel de uma conta **já existente**, `My Billing Account`, com o mesmo identificador visto antes no AI Studio e aviso `Seu teste gratuito exige um pré-pagamento`. Logo, o crédito **existe como benefício, mas ainda não foi resgatado**; o problema não é simplesmente falta de uma conta. Não criar uma segunda conta nem pagar por inferência. Verificar, em modo somente leitura, se a conta existente tem status ativo e se o titular dispõe da permissão `billing.accounts.redeemPromotion` no painel de permissões. O FAQ Google atribui a ausência da conta no seletor do benefício a essa permissão; o aviso de pré-pagamento pode ser um bloqueio adicional, ainda não confirmado. A API Gemini do projeto não deve ser acionada com o saldo atual. Um *spend cap* do Vertex AI pode reduzir o risco de excesso, mas a documentação oficial informa possível cobrança por atraso na aplicação do limite; não é garantia absoluta de gasto zero.

Outra captura de **Gerenciamento da conta de faturamento → Suas contas de faturamento** mostra zero contas sob o filtro `Status: Ativa`, enquanto a aba `Seus projetos` confirma `Content IA` vinculado a `My Billing Account`. O próximo diagnóstico é remover esse filtro para ler o status real da conta. Vínculo de projeto não confirma estado faturável. Se a conta continuar indisponível após verificar o status e a permissão, não afirmar que o crédito de US$ 10 está utilizável.

Há um papel `Admin da conta de faturamento (1)` no painel, mas a captura não mostra a identidade desse administrador. `Reabrir conta de faturamento` aparece desabilitado. Com a exigência do operador de nenhum desembolso, não reabrir nem pagar nesta fase.
